Design system

Every token and component below is rendered live from /style.css — the same stylesheet the real site pages (index, book pages) load. Nothing on this page is hand-duplicated; if a value here looks wrong, the fix belongs in static/style.css, and it will show up on both this page and the live site the next time gttp build runs. Full rationale in DESIGN.md at the repo root.

Color

Dominant cream/navy with a single burnt-orange accent used like a highlighter — never diluted into a second competing hue. Every token is a CSS custom property; the whole palette flips automatically for dark mode (try the toggle, top right).

Type

Two faces: Iowan Old Style (display — book titles, headings, the pull-quote) for literary warmth, and the system sans (body) for legibility at reading length. No webfont download: both resolve from each OS's built-in serif/sans stack, keeping the site fast and license-free.

The signature control — the annotated pull-quote

This is the one thing every visitor reads: the book's core idea, styled like a sentence a reader would highlight and mark with an asterisk in the margin. It is the single most load-bearing component in the system — everything else (the h2 dash, the tag pills, the underline color) is drawn from the same "marker" vocabulary it establishes.

Small habits compound into big results — the system you build matters more than the goal you set.
